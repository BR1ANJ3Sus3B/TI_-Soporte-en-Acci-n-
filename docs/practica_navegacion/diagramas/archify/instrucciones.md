# Instrucciones para ejecutar Archify después

1. Desde una instalación de Archify, cree una especificación de tipo `workflow` a partir de `nodos.json` y `transiciones.json`.
2. Use el prompt de `prompt-archify.md`; conserve IDs P01–P20 y las condiciones.
3. Valide y entregue el HTML con los comandos indicados por la instalación de Archify.
4. Verifique que los enlaces a los recursos usen rutas web relativas, no rutas `C:\`.

Archify no fue ejecutado durante esta práctica: estos archivos son material de preparación.
