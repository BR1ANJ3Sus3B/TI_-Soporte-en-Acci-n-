# Trazabilidad de requerimientos

Se reutilizan solamente los IDs existentes en `docs/proyecto/README.md`. RF-05 controla permisos; RF-06/RF-07 cubren misiones; RF-10 perfil; RF-14 progreso/evaluacion; RF-16 contenido; RF-20 cuentas. Las pantallas SOP01–SOP03 se etiquetan como **pendiente de requisito especifico** para no inventar identificadores.

Las restricciones por rol se detallan en `roles-permisos.md`; la interfaz administrativa no se interpreta como evidencia de backend implementado.
