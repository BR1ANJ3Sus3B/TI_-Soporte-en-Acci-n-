# Documentación

Documentación del proyecto "TI: Soporte en Acción".

## Organización

```
docs/
├── README.md               # Este documento
├── proyecto/               # Visión general y alcance del proyecto
├── requerimientos/         # Requerimientos funcionales y no funcionales
├── historias-de-usuario/   # Historias de usuario
├── arquitectura/           # Arquitectura del sistema
├── diseno/
│   ├── bocetos-movil/      # Bocetos de la aplicación móvil
│   ├── bocetos-web/        # Bocetos de la aplicación web
│   ├── paleta-de-colores/  # Paleta de colores
│   └── personajes/         # Diseño de personajes
├── pruebas/                # Planes y resultados de pruebas
└── manuales/               # Manuales de usuario y de desarrollo
```

## Secciones

- **proyecto**: descripción, objetivos y alcance.
- **requerimientos**: lo que el sistema debe hacer.
- **historias-de-usuario**: necesidades desde la perspectiva del usuario.
- **arquitectura**: componentes, diagramas y decisiones técnicas.
- **diseno**: bocetos, paleta y personajes.
- **pruebas**: estrategia y evidencia de pruebas.
- **manuales**: guías de uso y de desarrollo.

## Estado actual

Las carpetas y este índice se crearon como parte de la organización inicial. El contenido detallado se irá agregando conforme avance el proyecto, principalmente desde la rama `docs/documentacion`.
