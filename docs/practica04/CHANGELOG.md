# Changelog · Práctica 04

Todas las modificaciones relevantes de esta práctica. Formato basado en
[Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/).

## [1.1.0] - 2026-10

### Añadido
- Enlaces profundos por hash: cada componente del canvas (`#solucion`, `#usuarios`, …)
  y cada nodo de la arquitectura (`#arch-keycloak`, …) se puede compartir por URL.
- Botón **Copiar enlace** en la ficha de cada componente.
- Favicon SVG propio y `theme-color` en el canvas.
- Metadatos sociales (Open Graph y Twitter Card) para compartir la práctica.
- Página `404.html` personalizada para GitHub Pages.
- `robots.txt` y `sitemap.xml` del portafolio.
- `.editorconfig` para unificar estilo e indentación del repositorio.

## [1.0.0] - 2026-10

### Añadido
- Business Model Canvas interactivo con los **7 componentes** del Proyecto Integrador
  *TI: Soporte en Acción*: problema, usuarios, propuesta de valor, solución, actividades,
  recursos y resultados.
- Diagrama de flujo macro entre componentes con relaciones y verbos enlaces.
- Arquitectura interactiva (usuarios → Keycloak → Unity / Flutter / PWA → API → MongoDB)
  y tarjetas de soporte (Docker, Grafana, Git/GitHub, GitHub Pages).
- Flujos de proceso (jugador, administrador, contenido y autenticación).
- Elementos de gamificación, personajes y destacado de la propuesta de valor.
- Buscador de componentes, tooltips, resaltado cruzado y modal de detalle.
- Entregables generados con Archify en `docs/business-model-canvas/`.
